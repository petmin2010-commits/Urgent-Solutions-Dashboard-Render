# مياه المدينة — PWA Business Application

تطبيق ويب تقدمي PWA يعمل على الجوال والديسكتوب، ويستخدم قاعدة بيانات مستقلة بدل Google Sheets.

## التشغيل المحلي

1. افتح PowerShell داخل مجلد المشروع.
2. نفذ:
   ```powershell
   npm.cmd install
   npm.cmd start
   ```
3. افتح:
   `http://localhost:3035`

## الدخول المحلي الأولي

- البريد: `admin@madinah-water.local`
- كلمة المرور: `Madinah@2026`

يجب تغيير بيانات الدخول قبل أي نشر إنتاجي.

## المكونات الحالية

- شاشة إدخال موحدة للحالات.
- سجل أعمال قابل للبحث والتعديل.
- قاعدة بيانات SQLite محلية.
- Users / Roles / Permissions.
- Audit Log.
- رفع صور وفيديو وPDF.
- قوائم إدارية للمناطق والمراقبين والمقاولين وأنواع الانكسار وحالات الإصلاح.
- PWA Manifest + Service Worker.
- تصميم متجاوب للموبايل والديسكتوب.

## المرحلة اللاحقة

قبل النشر الإنتاجي على Render سيتم إضافة PostgreSQL كقاعدة البيانات الإنتاجية وترحيل نفس الـSchema إليها، ثم ربط المشروع بـGitHub وRender.
